# Collabo IDE

> **로컬 LLM을 위한 가볍고 오픈소스 기반의 AI IDE**
>
> 재귀적으로 개발된 초경량 바이브코딩 도구 / 지금은 바보같지만 시간이 해결해줄겁니다!

## 🌀 재귀적(Recursive) 철학

초기의 C 언어는 어셈블리어로 작성되었습니다. 이후 C는 스스로를 컴파일할 수 있게 되었고, 자기 자신을 개선하는 재귀적인 발전 과정을 거치며 성장했습니다.

**Collabo IDE 역시 같은 철학을 추구합니다.**

우리는 AI를 활용해 도구를 만들고, 그 도구를 활용해 더 나은 AI 도구를 만듭니다. 이러한 재귀적 순환을 통해 인간과 AI가 함께 발전하는 개발 생태계를 만들어 가고자 합니다.

---

## 📐 설계 원칙

### 최소함으로 확장성을 담다

AI의 능력은 빠르게 발전하고 있습니다.

Collabo IDE는 수많은 기능을 덧붙여 복잡한 도구가 되는 대신, 최소한의 인터페이스와 유연한 구조를 유지합니다. AI가 더욱 강력해질수록 이 친구가 알아서 할거에요.

### Workspace 중심 보안

보안은 선택 사항이 아닙니다.

모든 AI 작업과 파일 접근은 독립된 Workspace 안에서 수행됩니다. 이를 통해 심플한 자동화를 제공하면서도 사용자의 로컬 환경을 보호합니다.

---

## ⚡ 단순함이 가장 중요합니다

복잡한 설정은 우리의 적입니다.

### Python과 LLM만 있으면 충분합니다

Python과 LLM만 준비되어 있다면 시작할 수 있습니다.

### OpenAI 호환

로컬 모델이든 클라우드 모델이든 OpenAI 호환 API를 통해 익숙하고 일관된 사용 경험을 제공합니다.

### Zero Friction

Ollama, llama.cpp, 다양한 AI API까지.

원하는 모델만 선택하세요. 나머지는 Collabo IDE가 처리합니다.

---

## 🚀 시작하기

1. Python을 설치합니다. 
2. 로컬 LLM(Ollama, llama.cpp 등)을 실행하거나 API 키를 준비합니다.
3. Collabo IDE를 실행합니다.
4. AI 엔드포인트와 Python 경로를 설정합니다.
5. 작업할 Workspace를 선택합니다.
6. AI에게 원하는 작업을 요청합니다.

예시:

* "Hello World 프로그램 만들어줘."
* "이 폴더에 간단한 웹 서버를 만들어줘."
* "프로젝트 구조를 개선하고 코드를 리팩터링해줘."

그냥 시키세요. 그리고 갈구세요 (...)

## ✨ 주요 기능

* **재귀적 개발(Recursive Development)** — 도구를 이용해 도구 자체를 개선하는 개발 방식
* **로컬 우선 AI(Local-First AI)** — 데이터를 직접 통제할 수 있는 로컬 LLM 기반 환경
* **가벼운 인터페이스(Lightweight Interface)** — AI 중심 워크플로우에 최적화된 미니멀 UI
* **Workspace 보안 모델(Workspace Security)** — 안전한 코드 생성과 실행을 위한 격리 환경
* **OpenAI 호환(OpenAI-Compatible)** — 로컬 모델과 클라우드 모델을 동일한 방식으로 활용 가능
