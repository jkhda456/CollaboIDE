## 🌀 Recursive Philosophy

The early versions of the C programming language were written in assembly language. As C matured, it became capable of compiling itself, creating a recursive cycle of self-improvement.

**Collabo IDE follows the same philosophy.**

We use AI to build tools, then use those tools to build better AI-powered tools. Through this recursive process, we aim to create an ecosystem where humans and AI continuously evolve together.

---

## 📐 Design Principles

### Minimalism for Scale

AI capabilities continue to improve at an extraordinary pace.

As AI continues to improve, we expect most of our roadmap to complete itself. 😄

### Workspace-Centric Security

Security is not optional.

All AI actions and file access operate within workspaces. This approach allows automation while keeping the user's local environment protected and under control.

---

## ⚡ Simplicity First

Complex setup is the enemy.

### Just Python & LLM

If you have Python and an LLM, you're ready to go.

### OpenAI-Compatible

Whether you're using a local model or a cloud provider, the experience remains familiar and consistent through OpenAI-compatible APIs.

### Zero Friction

From Ollama and llama.cpp to cloud APIs, choose the model provider you prefer and start building immediately.

---

## 🚀 Getting Started

1. Install Python.
2. Launch a local LLM (Ollama, llama.cpp, etc.) or prepare an API key.
3. Start Collabo IDE.
4. Configure your AI endpoint and Python path.
5. Select a project workspace.
6. Tell the AI what you want.

Examples:

* "Create a Hello World application."
* "Build a simple web server in this folder."
* "Refactor this project and improve code quality."

Just tell it what to do. Then relentlessly ask for revisions.

## ✨ Key Features

* **Recursive Development** — Improve the tool using the tool itself.
* **Local-First AI** — Run with local LLMs and maintain control of your data.
* **Lightweight Interface** — Minimal UI optimized for AI-driven workflows.
* **Workspace Security** — Isolated environments for safe code generation and execution.
* **OpenAI-Compatible** — Works with local and cloud-based model providers.
